This is a branch off the Ising-Model project, you can check my profile to see more. I cleared many of the files here for a lack of immediate optimization needs.
This is a Spherical Ising Spin Glass model intended to simulate first noninteger values for the Ising Model the up to a global symmetry, then mapping specific problems onto this spin glass model, from there developing a loss landscape from it and performing analysis on the resulting output.
